# torch is deliberately not pinned to an exact build.
#
# The wheel is platform specific: the default PyPI wheel on Linux bundles CUDA
# and costs roughly 2.5GB, which does not fit on a small VM. CPU-only hosts
# must install it from the CPU index FIRST, so sentence-transformers cannot
# pull the CUDA build in as a dependency:
#
#     pip install torch --index-url https://download.pytorch.org/whl/cpu
#     pip install -r requirements.txt
#
# Verified on 2.12.0 (local) and 2.14.0+cpu (deployment).
torch>=2.12
